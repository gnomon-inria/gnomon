# Cell Image Quantification Workspace

The Cell Image Quantification Workspace allows to compute properties over the cells of a CellImage form and to display them in a 2D interactive figure.

Depending on the chosen plugin, the properties are computed either only on the CellImage itself, or using an optional Image a input. In any case, cell properties are added to the input CellImage, and a DataFrame representing the data asociated with each cell is returned as an output.
