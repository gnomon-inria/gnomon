# `dtkcore` Parameters

The `dtkcore` Python module provides for a variety of classes for different types notably for
integers, real numbers, character strings, boolean and so on:

## simple
- dtk::d_string

## Numeric
- dtk::d_uchar
- dtk::d_char
- dtk::d_uint
- dtk::d_int
- dtk::d_real
- dtk::d_bool

## List parameters
- dtk::d_inliststring
- dtk::d_inlistreal
- dtk::d_inlistint

## List of List
- dtk::d_inliststringlist

## Path
- dtk::d_path

## Range
- dtk::d_range_uchar
- dtk::d_range_char
- dtk::d_range_uint
- dtk::d_range_int
- dtk::d_range_real
