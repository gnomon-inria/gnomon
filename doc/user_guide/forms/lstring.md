# LString

![Gnomon LString illustration](../../_static/user_guide/lstring.png){width=200px class="sd-rounded-1 sd-shadow-sm" align=center}

A gnomon LString is a data strucure which represents the temporal evolution of a branching structure, as generated by a [Lindenmayer System](https://en.wikipedia.org/wiki/L-system)

## Default implementation

LStrings are implemented in the package [gnomon_package_treelsystem](../../plugins/packages/gnomon_package_treelsystem).
This package includes a reader, a writer and several visualization plugins for LStrings.

The default data class implementing LString in gnomon is `lStringDataLPy` that relies on the L-System implementation
provided by the [L-Py](https://lpy.readthedocs.io/en/latest/) Python package.  

The default reader of lstring form is **lStringReaderText** which reads a lstring from a plain text conforming with the [nested brackets representation](https://lpy.readthedocs.io/en/latest/user/lsystems.html?highlight=brackets#string-representation) and saved as a `.txt` file.
